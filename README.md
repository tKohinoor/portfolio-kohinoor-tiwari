# Kohinoor Tiwari — Portfolio

A responsive personal portfolio showcasing Kohinoor Tiwari's background, selected projects, skills, education, and contact links. It is built with plain HTML, CSS, and JavaScript, with no build step or package installation required.

## Run locally

Open `index.html` in a web browser, or serve the project directory with a local web server. For example, with Python installed:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Project files

- `index.html` — portfolio content and page structure
- `style.css` — layout, responsive styling, and visual design
- `script.js` — page interactions, scroll effects, and CV download

## Customize

Edit the content and links in `index.html`, update styles in `style.css`, and adjust interactive behavior in `script.js`. The portfolio can be deployed to any static web host.
